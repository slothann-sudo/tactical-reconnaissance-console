# 有人车—无人机协同侦察实验界面

## 目标
制作一套 16:9 横向战术指挥控制界面，准确呈现“普通负荷、默认持续运行、无突发 UAV 次任务”的实验母版状态。

## 实现内容
- 重建首页为单屏指挥控制台，使用深蓝、暗灰、青绿与荧光蓝的克制军工视觉系统。
- 顶部加入精简系统状态栏，显示车辆自动模式、R03 区域、3 架 UAV 在线、任务阶段与运行时间，全部保持正常状态。
- 中央制作可缩放适配的战术态势图：数字网格、简化地形、起点/终点/车辆当前位置、已行驶实线与未来虚线、车辆雷达扫描、T01–T03 目标、多架 UAV 航线/方向/搜索扇区及协同关系。
- 右侧制作 3 架 UAV 的低显著状态监控面板，显示区域、方向、进度和微型雷达，全部为正常侦察中。
- 底部突出“最高威胁目标”持续判断区，仅提供 3 张完全一致的候选目标卡片，并支持选择交互。
- 增加低显著系统消息栏，仅展示导航、网络与前出侦察正常运行信息。
- 不加入弹窗、告警、红色强调、倒计时、声音提示、人工介入请求或任何新任务入口。

## 视觉与动效
- 使用紧凑的等宽/窄体字排版、细描边透明面板、刻度与战术符号，避免游戏化和卡通感。
- 仅保留低强度扫描线、雷达旋转、路径流动与状态微动效，并遵循减少动态效果设置。
- 保证桌面 16:9 完整呈现，同时在较窄屏幕保持内容可读且不重叠。

## 技术细节
- 使用语义化设计变量集中定义颜色、阴影、边框、字体与动效。
- 使用 React 与内联 SVG 构建精密态势图，避免外部图片依赖。
- 为首页补齐独立页面标题、描述及社交分享元数据。
- 完成后通过实际预览截图检查 16:9 与窄屏布局、文字边界、层级及无告警状态。
